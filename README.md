## 填了码没打折，基本是这三件事

**第一，选了月付。** 洛杉矶这几个码里，EB 8 折明确写「非月付」，T1 两个码都要求年付，Pro/EB 的 85 折要求年付。月付勾上去再提交，码不会生效。买了没折扣的人，绝大多数卡在这一步。

**第二，一单只能用一个码。** 没有叠加。9 折和 85 折不能一起用，85 折的 10% 返现也不会因为再填一个码而变多。选一个最狠的就行。

**第三，码和系列不匹配。** `LAX-EB-LAUNCH-NON-MONTHLY-RECURRING-20OFF` 只认 EB，拿到 Pro 或 T1 的购物车里填一定失败；`LAX-T1-ANNUALLY-RECUR-30-OFF` 反过来只认 T1。

正确操作只有一条路径：套餐选好 → 计费周期选季付或年付 → 进购物车 → 找到 **Apply Promo Code**（有的页面写作 Promotional Code）输入框 → 粘贴优惠码，别手打，这一串字符里的大小写和连字符错一个就失败 → 点 **Validate Code** → 看页面总价有没有实时变化 → 确认折扣显示正确再付款。

## 循环折扣到底省多少

「循环」两个字值多少钱，拿 8 折算一遍最清楚。假设某套餐原价 $100/年，8 折后每年 $80。

- 两年：$160。
- 同样价格但只给首年优惠的商家：第一年 $80，第二年恢复 $100，两年 $180。
- 三年差距拉大到 $60，而且 DMIT 这边第三年、第四年仍然是 $80。

DMIT 的折扣码是续费同价，没有「首年特价、续费翻倍」那套。这一点比折扣本身更重要：一个首年 5 折、续费原价的码，长期算下来可能还不如一个老老实实的 8 折循环。

## Pro 还是 EB：按运营商决定，不是按预算

这两条线价差不小。按整理页报价，EB.TINY 季付 $28.88，Pro.TINY 季付 $37.99，再叠上 EB 的 8 折和 Pro 的 9 折，实际到手价差接近一半。所以问题不是「哪个更好」，而是「你多付的这一档能不能感知到」。

**电信用户优先 Pro。** 去程 CN2 GIA 对电信的收益最明显，晚高峰的差别也确实存在。

**联通、移动用户选 EB 就够。** EB 回程走 CMIN2，本来就是对着联通移动优化的，日常使用和 Pro 的差距比价差小得多。这一档差价省下来，够你把 EB 的配置往上提一级。

**只跑海外流量、不需要大陆优化**：T1。它的延迟和稳定性不适合拿来要求国内访问体验，但流量大、超量限速不停机，价格是三个系列里最低的。

## 几个容易踩到的限制

**热门套餐会缺货。** 香港 Pro 系列尤其明显，洛杉矶的入门档也会间歇性断货。看到有货别拖，DMIT 不是那种随时下单随时有的商家。

**IP 被封可以换，但有条件。** 每 15 天能免费换一次，限 Premium 和 Eyeball 系列，前提是确认 IP 确实被封。T1 不在这个政策里。

**退款条款各来源说法不一致。** 有的整理页写 3 天内、流量消耗不超过 30GB 可全额退，30 天内按剩余比例退；另一个来源写 7 天无理由退款。两种说法都没有附官方条款链接，我不替它做承诺。下单前自己去官网条款页确认一遍，别按某一篇整理文章的天数去规划。

**支付和沟通没有门槛。** 支持支付宝、微信、PayPal、信用卡，有中文客服，国内用户从注册到付款不需要额外折腾。

**防护和在线率。** 官方标注 5Tbps+ 的 DDoS 防护能力，SLA 写的是 99.9% 在线率。这类指标看官方页面原话更稳妥。

## 常见问题

**优惠码在哪个页面填？**
购物车页面，找 Apply Promo Code 或 Promotional Code 输入框，粘贴后点 Validate Code，价格实时刷新。不在套餐选择页填。

**续费还用重新填码吗？**
不用。标注为 Recurring 的码在续费时自动按折扣价结算，续费和首次购买同价。

**月付真的一个码都用不了吗？**
洛杉矶这边，EB 8 折要求季付及以上，T1 两个码都要求年付。9 折那个码写的是「任意套餐」，没标周期门槛，月付能不能触发需要你自己在购物车验证，我没法确认。

**Pro 和 EB 的线路差别到底在哪？**
Pro 是三网回程 CN2 GIA、电信联通去程也走 CN2 GIA；EB 是三网回程 CMIN2。对电信用户，Pro 的优势更明显；联通移动用户用 EB，感知差距小。

**IP 被墙了怎么办？**
Premium 和 Eyeball 系列每 15 天可免费更换一次，需确认 IP 确实被封。
